# Third Party Notices

`@usman-a/pi-ui-studio` bundles unmodified (or minimally transformed) copies of
two upstream projects. Studio's own orchestration code is MIT licensed (see
[LICENSE](./LICENSE)); the bundled work below stays under its original license
and copyright.

Everything under `vendor/` is generated by `scripts/sync-upstream.mjs` from the
published npm artifacts and is never hand-edited. Per-file SHA-256 digests and
the exact upstream versions are recorded in
[`vendor/manifest.json`](./vendor/manifest.json).

Copyright (c) 2026 Leandro (LePro10) — <https://github.com/LePro10/omp-designer>
npm package author: Leandro <lewerb1@wff.ch>

Bundled parts: the designer skill corpus under `vendor/omp-designer/skills/`,
the design reference dataset under `vendor/omp-designer/data/`, and the
deterministic validators `fix-ai-slop.mjs` and `analyze-layout.mjs`.

Note: the published npm tarball of `omp-designer` contains no `LICENSE` file;

below is reproduced for that upstream.

`design-md-single-contract` transform documented in `scripts/transforms/skill-md.mjs`.
